二、本地优先运行

BentoDesk 不需要账号或项目自建服务器，也不提供遥测、分析、广告、云存储或崩溃上传服务。除第四节说明的默认 GitHub 通道或受控 HTTPS 覆盖源产生的普通请求元数据外，软件不会上传个人数据、设备标识、使用记录、桌面文件列表或路径、图标、内容，或其他用户数据。

为了提供桌面整理功能，BentoDesk 只会在本机读取桌面元数据，以及你明确拖入、选择或绑定的文件与文件夹；这些处理均留在你的电脑中。外部链接和网络位置仅在你主动操作后交由 Windows 对应的默认应用打开；之后如有网络访问，属于 Windows 或该应用，不属于 BentoDesk。

三、文件与设置

BentoDesk 通过 Windows Shell 与文件交互。普通拖拽可以移动项目，按住 Ctrl 则请求复制。整理重要文件前，请保留独立备份。

应用设置仅保存在本机。卸载程序默认保留设置；只有你主动选择“删除用户设置和本地缓存”并再次确认后才会清除。删除 BentoDesk 设置不代表授权删除 Zone 中展示的桌面文件或文件夹。

四、更新

BentoDesk 的标准更新通道只会通过证书校验的 HTTPS 访问固定 endpoint https://api.github.com/repos/ZRainbow1275/bentodesk/releases/latest 及其精确安装包资源。受控的 BENTODESK_UPDATE_MANIFEST_URL 可选择 HTTPS、file 或本地覆盖源。选择自动检查周期后，调度器启动时会立即检查一次，之后按所选周期运行。默认设置为每周检查并开启自动下载；选择 Manual 会禁用定时检查，自动下载也可单独关闭。

默认通道的自动下载只会在核对 GitHub SHA-256 digest 后暂存精确的官方安装包；受控覆盖源声明的安装包也必须先通过 manifest SHA-256 或内置公钥 minisign 签名校验。安装始终需要用户明确操作。GitHub 或受控 HTTPS 覆盖源的主机可能按其自身政策接收源 IP 地址、BentoDesk User-Agent 等普通 HTTPS 请求元数据；BentoDesk 不会在这些请求中附带遥测或用户文件数据。
