2. Local operation

BentoDesk runs fully offline. It does not require an account or cloud service and does not collect or transmit personal data, device identifiers, usage analytics, crash reports, file lists, file contents, or any other information from your computer.

To provide its desktop-organizing features, BentoDesk reads local desktop metadata and the files or folders you explicitly drag, select, or bind. This processing stays on your computer. External links and network locations are opened only after your explicit action and are handed to the corresponding default Windows application; any network access then belongs to Windows or that application, not to BentoDesk.

3. Files and settings

BentoDesk uses Windows Shell operations for file interaction. A normal drag can move an item; holding Ctrl requests a copy. Keep independent backups of important files before reorganizing them.

Application settings are stored locally. The uninstaller preserves them by default. They are removed only when you explicitly select the data-removal option and confirm it. Removing BentoDesk settings never authorizes deletion of the desktop files or folders represented inside a Zone.

4. Updates
