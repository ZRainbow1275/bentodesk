# BentoDesk 2.0.2

## English

BentoDesk 2.0.2 keeps the Live Folder picker inside the existing native
process. The Windows folder dialog now runs in the shell UI thread's OLE STA
instead of launching a temporary second `BentoDesk.exe`.

It includes the complete native 2.0 feature set from 2.0.1: continuous Zone
motion, safe Shell copy/move handling, native settings and management tools,
plugins, English and Simplified Chinese, and the Win32 / Direct2D /
DirectComposition runtime.

Download `BentoDesk-2.0.2-windows-x64-portable.zip`, verify it with
`SHA256SUMS.txt`, extract it, and run `BentoDesk.exe`.

## 简体中文

BentoDesk 2.0.2 将实时文件夹选择器收回现有原生进程。Windows 文件夹对话框
现在直接运行在 Shell UI 线程的 OLE STA 中，不再临时启动第二个
`BentoDesk.exe`。

本版同时包含 2.0.1 的完整原生功能：连续的 Zone 动画、安全的 Shell
复制/移动处理、原生设置与管理工具、插件、English 与简体中文，以及
Win32 / Direct2D / DirectComposition 运行时。

下载 `BentoDesk-2.0.2-windows-x64-portable.zip`，使用 `SHA256SUMS.txt`
核验后解压并运行 `BentoDesk.exe`。
