# BentoDesk 2.0.1

## English

BentoDesk 2.0.1 packages the native Rust rewrite for everyday use.

- continuous Zone expansion, reversal, resizing, and Stack hand-offs;
- corrected icon removal, Shell copy/move handling, and collision-safe file transfers;
- native editors, settings, search, smart grouping, batch layouts, snapshots, and plugins;
- English and Simplified Chinese, selected from the Windows UI language on first launch;
- a single-process Win32 / Direct2D / DirectComposition runtime with no bundled web engine.

Download `BentoDesk-2.0.1-windows-x64-portable.zip`, verify it with
`SHA256SUMS.txt`, extract it, and run `BentoDesk.exe`.

BentoDesk 2.0.1 整理并发布 Rust 原生重构版。

下载 `BentoDesk-2.0.1-windows-x64-portable.zip`，使用 `SHA256SUMS.txt`
