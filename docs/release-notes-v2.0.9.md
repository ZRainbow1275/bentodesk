# BentoDesk 2.0.9

## English

BentoDesk 2.0.9 updates the project documentation and community launch copy.
The English and Simplified Chinese READMEs now link Linux Do and NodeSeek in
the acknowledgements. Application behavior is unchanged from 2.0.8.

The Windows setup and portable packages are rebuilt from this exact source
commit. Setup remains per-user, offline and bilingual; uninstall preserves
settings unless deletion is separately selected and confirmed.

## 简体中文

BentoDesk 2.0.9 更新了项目文档与社区发布稿。中英文 README 的致谢现已加入
Linux Do 与 NodeSeek 的链接。应用功能与 2.0.8 保持一致。

Windows 安装版与便携版将基于本次提交重新构建。安装程序继续采用当前用户权限、
完全离线并提供中英双语；卸载默认保留设置，只有另行选择并确认后才会清除
BentoDesk 自身状态。
