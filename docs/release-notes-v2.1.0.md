# BentoDesk 2.1.0

## English

BentoDesk 2.1.0 keeps Zone and Stack capsules inside the current Windows work
area, including scaled displays and taskbars on any edge. Saved positions are
repaired against the visible capsule footprint and remain stable across restart
and work-area changes.

Zone panels again expand toward the available quadrant: capsules on the right
or bottom anchor their panels to the matching edge. Paint, hit testing, search,
drag and drop, and mirrored resizing now consume the same resolved geometry;
Stack management surfaces anchor to the actual Stack capsule.

Zone Editor column choices now remain exact in narrow panels instead of being
silently reduced. Native file icons also preserve RGBA colour channels, and the
old affected icon-cache revision is refreshed automatically at startup.

## 简体中文

BentoDesk 2.1.0 让 Zone 与 Stack 胶囊始终留在当前 Windows 工作区内，覆盖缩放
显示器以及位于任意边缘的任务栏。已保存位置会按真实可见胶囊范围修复，并在重启
和工作区变化后保持稳定。

Zone 面板恢复按可用象限展开：位于右侧或下侧的胶囊会把面板锚定到对应边缘。
绘制、命中、搜索、拖放与镜像缩放现在共用同一份已解析几何；Stack 管理表面也会
锚定到真实的 Stack 胶囊。

Zone 编辑器设置的网格列数现在会在窄面板中原样生效，不再被静默降列。原生文件图标
也会正确保留 RGBA 颜色通道；启动时会自动刷新受影响的旧版图标缓存。
