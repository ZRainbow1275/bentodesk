# BentoDesk 2.0.0

## 简体中文

BentoDesk 2.0 把桌面 Zone、拖放、搜索、主题、插件、智能分组、批量管理、快照与时间线迁移到单进程 Windows 原生运行时。

- Rust 2024 + Win32 + Direct2D / DirectWrite / DirectComposition；
- 不再携带 Tauri、WebView2、Chromium 或 Node.js 运行时；
- 用户可见产品、窗口与可执行文件统一为 `BentoDesk 2.0.0`；
- Tauri 1.3.0 源码保留在 `v1.3.0` 与 `archive/tauri-1.x`；
- 默认简体中文，可在设置中切换 English。

下载 `BentoDesk-2.0.0-windows-x64-portable.zip`，核对同页 `SHA256SUMS.txt` 后解压运行 `BentoDesk.exe`。首版只发布已验证的 Windows x64 便携包。

## English

BentoDesk 2.0 moves Zones, drag and drop, search, themes, plugins, smart grouping, batch management, snapshots, and the timeline to a single-process native Windows runtime.

- Rust 2024 + Win32 + Direct2D / DirectWrite / DirectComposition;
- no bundled Tauri, WebView2, Chromium, or Node.js runtime;
- the user-facing product, windows, and executable are unified as `BentoDesk 2.0.0`;
- the Tauri 1.3.0 source remains available at `v1.3.0` and `archive/tauri-1.x`;
- Simplified Chinese is the default, with English available in Settings.

Download `BentoDesk-2.0.0-windows-x64-portable.zip`, verify it against `SHA256SUMS.txt` on this release, extract it, and run `BentoDesk.exe`. The first release provides the verified Windows x64 portable package only.
