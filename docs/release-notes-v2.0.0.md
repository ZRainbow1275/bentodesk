# BentoDesk 2.0.0

## English

BentoDesk 2.0 rebuilds Zones, drag and drop, search, themes, plugins, smart grouping, batch management, snapshots, and the timeline on a single-process native Windows runtime.

- Rust 2024 + Win32 + Direct2D / DirectWrite / DirectComposition;
- no bundled Tauri, WebView2, Chromium, or Node.js runtime;
- one product name throughout: `BentoDesk`;
- the Tauri 1.3.0 source remains at `v1.3.0` and `archive/tauri-1.x`;
- English and Simplified Chinese are included; first launch follows the Windows display language.

Download `BentoDesk-2.0.0-windows-x64-portable.zip`, verify it against `SHA256SUMS.txt` on this release, extract it, and run `BentoDesk.exe`. The first release provides the verified Windows x64 portable package only.

## 简体中文

BentoDesk 2.0 将桌面 Zone、拖放、搜索、主题、插件、智能分组、批量管理、快照与时间线重写为单进程 Windows 原生程序。

- Rust 2024 + Win32 + Direct2D / DirectWrite / DirectComposition；
- 不携带 Tauri、WebView2、Chromium 或 Node.js 运行时；
- 项目、窗口与可执行文件统一使用 `BentoDesk`；
- Tauri 1.3.0 源码保留在 `v1.3.0` 与 `archive/tauri-1.x`；
- 内置 English 与简体中文，首次启动跟随 Windows 界面语言。

下载 `BentoDesk-2.0.0-windows-x64-portable.zip`，核对同页 `SHA256SUMS.txt` 后解压运行 `BentoDesk.exe`。首版只发布已验证的 Windows x64 便携包。
