# Column — visual spec (snap.md)

- **Direction**: vertical main axis (`Direction::Column`).
- **Defaults**: `gap=0`, `align=Stretch`, `justify=Start`, `padding=ZERO`, `margin=ZERO`.
- **Sizing**: `width=Auto` / `height=Auto` — fills parent allocation.
- **No chrome**: zero background, zero border, zero shadow — purely structural.
- **Animation**: none — passive container.
- **Hover/active**: none — propagates to children.
