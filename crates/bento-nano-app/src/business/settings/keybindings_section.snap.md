# KeybindingsSection — Visual Spec

Source: `bentodesk/src/components/Settings/KeybindingsSection.tsx` (139 LOC) + `KeybindingsSection.css`.

- **Modal scrim (`.keybindings-panel__scrim`):** `position: fixed`, `inset: 0`, `rgba(0,0,0,0.45)` bg, flex centered, `z-index: 1001` (sits above SettingsPanel which is z 2000 — so it MUST mount as a sibling of SettingsPanel, not a child; the React baseline mounts via portal to `<body>`).
- **Panel card (`.keybindings-panel__card`):** `width: min(560px, 92vw)`, `max-height: 76vh`, `overflow: auto`, `var(--surface-expanded)` bg, `var(--text-primary)` fg, 1 px `var(--border-expanded)` border, `var(--radius-expanded)` corners, `var(--blur-expanded)` backdrop-filter, `var(--shadow-expanded)`.
- **Header (`.keybindings-panel__header`):** flex space-between, `padding: 16px 20px`, 1 px `var(--border-expanded)` bottom border. Title `<h2>` 1.05 rem (~17 px) Semibold. Close button: transparent bg, `font-size: 1.2rem`, `padding: 4px 10px`, `border-radius: 6px`. Hover: `var(--surface-hover)` bg.
- **List (`.keybindings-panel__list`):** unstyled `<ul>`, `padding: 12px 0`.
- **Row (`.keybindings-panel__row`):** **CSS grid** `grid-template-columns: 1fr auto auto`, **12 px gap**, `padding: 8px 20px`, `align-items: center`. (Note: snap was wrong — the React baseline does NOT use a 4-column [200/120/80/64] track — it's `1fr auto auto`.)
- **Label (`.keybindings-panel__label`):** 0.92 rem (~15 px), default weight.
- **Chip (`.keybindings-panel__chip`):** monospaced ("SF Mono", Consolas, ui-monospace), 0.85 rem (~14 px), `var(--surface-hover)` bg, 1 px `var(--border-zen)` border, `border-radius: 6px`, `padding: 3px 10px`, `min-width: 130px`, `text-align: center`. **Recording state:** chip text becomes the localised "Recording…" placeholder; no special border/pulse in the React baseline (the snap previously fabricated a 1 s accent pulse).
- **Action buttons (`.keybindings-panel__btn`):** `var(--surface-hover)` bg, inherit color, 1 px `var(--border-zen)` border, `padding: 4px 10px`, `border-radius: 6px`, 0.8 rem (~13 px). Disabled: `opacity: 0.5`. Hover (non-disabled): `var(--surface-active)` bg. Two buttons inside `.keybindings-panel__actions` (6 px gap): Record + Reset. Record disabled when ANY other row is recording.
- **Conflict indicator (`.keybindings-panel__conflict`):** spans `grid-column: 1 / -1`, 0.8 rem `var(--accent-red)` text, `margin-top: 4px`. Two reasons: `"reserved"` → reserved-chord copy, otherwise "taken" copy.
- **Reserved chords:** `Alt+F4`, `Alt+Tab`, `Ctrl+Esc`, `Win+L`, `Win+D` (see `is_reserved_chord` — case-insensitive lookup).
- **Behaviour:** Record button → `setRecording(action)`; first non-Escape KeyboardEvent → `formatAccelerator(e)` → `setBinding(action, accel)` → `setRecording(null)`. Escape during recording cancels back to idle. `keydown` listener installed on `window` capture phase via `onMount`/`onCleanup`. Default bindings come from `keybindings` store — see `DEFAULT_KEYBINDINGS` constant (10 actions; mapped to `LABEL_MAP` translation keys). Dispatcher hook: per-row mutation emits `Command::SetSetting { key: "keybinding.<action>", value: SettingValue::Str(accel) }`.
